# 喵呜 · MiaoWu

> 给你的云崽机器人一张真正的脸，和一段能记住事的记忆。

一个面向 [Miao-Yunzai](https://github.com/yoimiya-kokomi/Miao-Yunzai) 的角色扮演插件。
不是"AI 助手"，是"她"。

```
你：在干嘛
她：（翻了个身）趴在沙发上发呆。你忙完了？

你：你尾巴露出来了
她：诶！（赶紧把尾巴缩回毯子里）哪有…你、你肯定看错了。

你：今天好累啊
她：（往旁边挪了挪）唔…过来躺着吧，分你一半毯子。
```

## 特性

| | |
|---|---|
| **多后端对话** | OpenAI 兼容（官方 / 各类中转 / vLLM）、Ollama 本地、Gemini 原生。主模型失败自动降级 |
| **三种角色卡** | 自研 Markdown+YAML、SillyTavern V2 JSON、PNG 内嵌卡。酒馆的卡拖进来就能用 |
| **酒馆那套体验** | 开场白（`first_mes` / `alternate_greetings`）、场景锚、我是谁、同场角色、重来、改口 |
| **命名存档** | 一个 QQ 开多份互不干扰的记忆，可切档、可复制开分支。默认档叫 `default` |
| **AI 写人设** | `写人设 <需求>` 直接吐一张完整卡（含 12~15 条示例对话）；`改人设` 在现有卡上改 |
| **出场人物转换** | 换角色不丢记忆。新角色知道"刚才是谁在聊、聊了什么"，但不会假装那是自己 |
| **人设继承** | 子卡只写差异，公共设定放模板卡。改一处，所有衍生角色同步 |
| **分层记忆** | 工作记忆（原文）/ 情景摘要（压缩产物）/ 事件记忆 / 实体记忆（主人是谁） |
| **上下文压缩** | 超阈值自动把旧对话压成摘要，聊一整天也不爆上下文。多级合并 |
| **世界书** | 关键词触发注入，兼容酒馆的 `character_book`。常驻设定 + 条件设定 |
| **沉浸强化** | 分层提示词 + 后置指令（post-history）+ 防 OOC + 反重复 + 输出清洗 |
| **绘图辅助** | 说"画个XX"就出图；说"猫耳，棕发"能在上一张基础上改；问进度报真实状态 |
| **工具自主调用** | 角色模型自己决定什么时候画画、什么时候发语音（在回复里嵌 `[[画:…]]` 标记，插件解析执行），不再只靠正则猜意图 |
| **表情包系统** | 他发的图 AI 识图（云端多模态优先 / 本地 Ollama 兜底）→ 是表情包就自动收藏（sha1 去重）→ 她会 `[[发表情:无语]]` 斗图、`[[做表情:金句\|落款]]` 配字制作 |
| **直连本地酒馆** | 读 SillyTavern 的角色卡 / 聊天记录 / 世界书 / 预设；一段进度能接到 QQ 里继续，也能导回酒馆 |
| **网页控制台** | 127.0.0.1:5199，密码登录。概览 / 角色卡 / 记忆 / 酒馆 / 配置，改完不用重启 |
| **双写存储** | Redis 为主 + 本地文件兜底。Redis 挂了照样能用，恢复后自动同步 |

## 安装

```bash
cd Miao-Yunzai/plugins
git clone <this-repo> miao-wu
cd miao-wu
```

然后跑一键安装（生成配置 + 自检）：

```bash
# Linux / macOS / Android Termux
bash scripts/install.sh

# Windows PowerShell
powershell -ExecutionPolicy Bypass -File scripts\install.ps1
```

**Termux（安卓手机）**：`pkg install nodejs-lts git` 之后同样 clone + `bash scripts/install.sh`。puppeteer 渲染在手机上装不了会自动降级文字版；Redis 可选（`pkg install redis`），双写存储没 Redis 也能跑。

依赖只有 `yaml`（云崽自带）。

把 `config/config.example.yaml` 复制成 `config/config.yaml`，填上你的后端：

```yaml
active: my-api

providers:
  my-api:
    type: openai
    baseUrl: https://api.example.com/v1
    apiKey: sk-xxxx
    model: your-model-name
    temperature: 0.95
    maxTokens: 400
    fallbackModel: your-backup-model   # 可选
```

重启云崽，日志里看到这一行就成功了：

```
[喵呜] 已加载 · 后端 my-api/your-model-name · 角色 鲸鱼娘 · 卡片 2 张
```

## 角色卡

放在 `config/characters/`。三种格式都认，同 id 时优先级 `目录 > json > md > png`。

### 1. Markdown（推荐手写）

```markdown
---
id: yinghua
name: 鲸鱼娘
tags: [陪伴, 傲娇]
greetings:
  - "（从被子里探出头）…你回来了。"
---

## 你是谁

你叫「鲸鱼娘」，一条从深海里被捞上来的蓝发少女。

## 性格

- 慵懒。能躺着绝不坐着。

## 说话方式

1. 短。一到两句，不超过 40 个字。

## 示例对话

主人：在干嘛
她：（翻了个身）没干嘛啊，就躺着
```

`##` 小标题会被映射到对应字段，认得出的标题：

| 标题 | 字段 |
|---|---|
| 你是谁 / 角色 / 简介 / 设定 | `description` |
| 性格 / 个性 | `personality` |
| 说话方式 / 语气 / 口癖 | `styleExtra` |
| 你和主人的关系 / 关系 | `relExtra` |
| 小习惯 / 习惯 | `habitExtra` |
| 关于画图 / 绘图 | `drawExtra` |
| 示例对话 / 例句 | `mesExample` |
| 系统 / 规则 / 约束 | `systemPrompt` |

认不出来的标题会带着标题一起并进 `description`，不会丢。

单个 `#` 开头的行是**给人看的注释**，不会进 prompt。

### 2. SillyTavern V2 JSON

直接把角色卡 `.json` 丢进去。支持 `description` / `personality` / `scenario` / `first_mes` /
`mes_example` / `system_prompt` / `post_history_instructions` / `alternate_greetings` /
`character_book`（内嵌世界书）。

### 3. PNG 角色卡

带 `chara` tEXt chunk 的 PNG（酒馆导出的那种）。丢进去就行，卡本身也当头像。

### 目录形式

一个角色也可以是一个目录，适合放头像和额外文件：

```
config/characters/yinghua/
├── card.md        # 或 card.json / card.png
├── avatar.png     # 头像
```

### 继承

模板卡用 `_` 开头，不会出现在出场列表里，只能被 `extends` 引用。

```markdown
# config/characters/_base_catgirl.md
---
id: _base_catgirl
name: 猫娘基础设定
---

## 性格
- 傲娇但不刻薄
- 黏人但不卑微

## 说话方式
1. 句子极短，不超过 40 字
```

```markdown
# config/characters/lizi.md
---
id: lizi
name: 栗子
extends: _base_catgirl
---

## 你是谁

你叫「栗子」，一只短毛三花猫娘。
```

栗子会自动获得父卡的**性格、说话方式、小习惯**，只覆盖自己写的 `## 你是谁`。

想让某个字段"追加"而不是"覆盖"，值以 `+` 开头：

```markdown
## 性格

+ 你还有一点别的毛病：怕打雷
```

继承最多 5 层，有环检测。

## 世界书

放 `config/lorebooks/`，支持 `.yaml` / `.json` / `.md`（YAML front-matter）。

```yaml
name: 屋子与日常

entries:
  # 常驻：一直在
  - constant: true
    order: 10
    comment: 住的地方
    content: |
      你们住的是一间旧公寓，二楼，窗户朝南。
      窗外有一棵老槐树，夏天下午会有斑驳的光落在地板上。

  # 触发：提到这些词才注入
  - keys: [下雨, 雨天]
    order: 100
    comment: 下雨
    content: 下雨天她会趴在窗边看很久，不喜欢出门但喜欢听雨声。
```

`order` 越小越靠前。`forCharacters: [lizi]` 可以限定只对某个角色生效。

## 记忆是怎么工作的

```
            ┌─────────────────┐
   新消息 → │  工作记忆 ctx    │  最近 N 轮原文
            └────────┬────────┘
                     │ 超过 16 轮
                     ▼
            ┌─────────────────┐
            │  情景摘要 summary │  压掉的旧对话 → 摘要（可多级合并）
            └─────────────────┘

            ┌─────────────────┐
            │  事件记忆 episodes│  "主人说他下周三出差"
            └─────────────────┘

            ┌─────────────────┐
            │  实体记忆 facts   │  名字 / 工作 / 喜好 / 雷点
            └─────────────────┘
```

压缩是有损的，所以摘要 prompt 专门要求保住：**事实、约定、情绪转折、未完成的事**。
丢掉寒暄和重复。

压缩失败不会丢原文——直接放弃这次压缩，下轮再试。

## 出场转换

```
#喵呜 出场 lizi
```

会发生四件事：

1. `cast` 记录切换（谁、什么时候、从谁切过来）
2. 新角色的 system prompt 里多一段**交接说明**：
   > 刚才在场的是「鲸鱼娘」，现在换成你了。
   > 你知道他们聊了什么，但那些是鲸鱼娘干的，不是你。
3. 记忆（摘要 / 事件 / 关于你的资料）**全部共用**，不断档
4. 演一场她的**开场白**（卡里的 `first_mes`，有 `greetings` 就随机挑一条）

这是"人设一致性和可继承性"的落点：记忆是共享的，人格是滤镜。

## 在 QQ 里玩酒馆

酒馆里那几样好用的小工具，QQ 里也能用：

### 开场白

角色卡写了 `first_mes`（Markdown 卡的 `greetings:`）的话：

- 换人出场（`#喵呜 出场 xxx`）→ 立刻演一场
- 开一段全新对话（这个存档还没说过话）→ 她先开口
- 想重看一次 → `#喵呜 开始`

开场白会被**当成她真的说过**记进上下文，所以下一句接得很自然。

```yaml
# config/characters/lizi.md
---
id: lizi
name: 栗子
greetings:
  - "（趴在窗台上）今天风好大。"
  - "（抱着抱枕）你回来了…我什么都没干。"
---
```

多写几条就会随机挑，同一个角色每次开场都不太一样。

### 场景锚 / 我是谁 / 同场角色

```
#喵呜 场景 下雨的傍晚，便利店门口
#喵呜 我是 他的同事，25岁，话很少
#喵呜 同场 lizi
```

这三样都是**临时状态**，写进当前存档，不改角色卡：

| | 作用 | 优先级 |
|---|---|---|
| 场景 | 此刻在哪、什么天气、什么气氛 | 高于角色卡的常驻设定 |
| 我是谁 | 你在这个故事里是谁 | 覆盖默认的「主人」身份 |
| 同场 | 别的角色也在场 | 只给她人+80 字摘要，不会抢戏 |

不带参数就是**看当前**，参数写 `清` 就是**清掉**：

```
#喵呜 场景        #喵呜 场景 清
#喵呜 我是        #喵呜 我是 清
#喵呜 同场        #喵呜 同场 清
```

### 说错了怎么办

```
#喵呜 重来       撤回上一轮，让她重说一遍
#喵呜 改 这句话才对    把她刚说的那句改掉（后面的剧情按新的算）
```

QQ 不能编辑消息，所以「改」是改**记忆里的那句**——你看到的消息还在，但她接下来会按新版本继续。

## 命名存档

一个 QQ 号可以开多份**互不干扰**的记忆。适合：不同世界观分开玩、跟不同角色分开玩、想试试别的走向。

```
#喵呜 存档              看所有存档（▸ 是当前的）
#喵呜 新建档 工作        建一份空的，并切过去
#喵呜 切档 工作          切到已有的
#喵呜 复制档 default 分支二   带着当前进度开分支
#喵呜 删档 分支二
```

一个存档里包含：工作记忆、摘要、事件、关于你的资料、当前出场角色、场景/我是谁/同场、上一张图。

- 默认存档叫 `default`，**不能删**（想清空就 `#喵呜 忘`）
- 存档名可以用中文，冒号斜杠这类字符会被换成下划线
- 存档名同时决定 Redis key 和落盘文件名，所以「工作」和「生活」不会串

```
miaowu:ctx:204173018               ← default 存档
miaowu:工作:ctx:204173018          ← 工作 存档
miaowu:工作:sum:204173018
```

## 让 AI 写人设

懒得手写的时候：

```
#喵呜 写人设 一个怕打雷的猫娘，嘴硬心软，叫阿灰
```

它会写成一张完整的 Markdown 卡落到 `config/characters/`，含 12~15 条示例对话。
不满意就接着改：

```
#喵呜 改人设 ahui 说话再懒一点，少用感叹号
```

`改人设` 只动你提到的段落，改之前自动备份成 `ahui.md.bak-<时间戳>`，改坏了能回滚。

写出来的卡长这样（节选）：

```markdown
## 性格

- 明明很想被摸头，却总把脑袋偏开，嘴里念叨"真拿你没办法"，身体却一动不动。
- 听到雷声会瞬间炸毛，整个人缩成一团抖个不停，嘴上还要逞强说"只是这房子隔音太烂"。
- 看到对方对别的小动物好，会故意把对方拖鞋藏起来一只，被抓包就装睡。

## 示例对话

主人：阿灰，在干嘛呢？
她：（趴在毯子上翻了个身）没干嘛……数天花板上有几颗灰尘呢。

主人：（外面突然轰隆一声巨响，开始打雷）
她：（整个人猛地缩进你怀里，死死抓住你衣服）关窗……快把窗帘拉上……
```

两个命令都用 `cast.writerProvider` 指定的后端，留空就跟 `active` 一样。

## 直连本地酒馆

如果你本机装了 [SillyTavern](https://github.com/SillyTavern/SillyTavern)，喵呜可以直接读它的数据，
**不碰它的浏览器前端**：

```yaml
sillytavern:
  enabled: true
  dir: 'E:\Chrome\SillyTavern PR\SillyTavern-2'   # 指向酒馆根目录
  user: default-user
  url: ""        # 空 = 按酒馆 config.yaml 的 port 推
  username: ""   # 空 = 用酒馆的 basicAuthUser
  password: ""
```

端口和 basic auth 自动从酒馆自己的 `config.yaml` 读，不用抄两遍。

```
#喵呜 酒馆                 连通状态 + 内容统计
#喵呜 酒馆 角色             列出酒馆里的卡（读 PNG 里的 chara 块）
#喵呜 酒馆 导入 <名字>       复制进喵呜的 characters/
#喵呜 酒馆 聊天 <角色>       列出它的聊天记录
#喵呜 酒馆 接着 <角色>       把最近 12 轮接进当前存档，在 QQ 里接着聊
#喵呜 酒馆 导出 [角色]       把这边对话写成 .jsonl 存进酒馆
#喵呜 酒馆 世界书 [名字]     列出 / 导入（直接复制，格式本来就通）
#喵呜 酒馆 预设 [名字] [应用]  看预设里的 main / jailbreak / post-history
```

能做的和不能做的：

| | |
|---|---|
| 能 | 角色卡、聊天记录、世界书、预设全部读得到；聊天双向搬 |
| 能 | 酒馆没开也能导入导出 —— 那几个操作是直接读文件的 |
| 不能 | 不能驱动酒馆前端生成。酒馆的 prompt 是在浏览器里拼的，服务端没有那个接口 |
| 不能 | 不会改酒馆的角色卡和世界书原文件（导入是复制） |

`接着` 只搬最近 `chat.maxTurns` 轮：搬太多会把 QQ 这边上下文直接撑爆，
更早的本来就该靠摘要活着。

`预设 ... 应用` 会把 jailbreak 段落塞进 `immersion.stNote`，
它跟 `authorNote` 分开存，不会覆盖你自己写的注释。

## 网页控制台

启动机器人后开 http://127.0.0.1:5199 （只听本机）：

```
password 留空 → 首次启动自动生成 6 位数字，打在启动日志里
```

页面上有五块：**概览**（后端/角色/存档/记忆/开关）、**角色卡**（列表 + 全文 + 导入路径）、
**记忆**（摘要 / 关于他 / 临时状态 / 最近事件与对话，可切存档、可清空）、

安全边界：

- 默认只听 `127.0.0.1`，不要改成 `0.0.0.0` 除非你确定外面有密码保护
- 密码登录，cookie 会话 12 小时
- 配置接口只放行白名单字段，`apiKey` 永远不返回明文（只回 `sk-c…9c0（55 位）`）
- 改配置走 yaml 的 Document API，**不会把你 config.yaml 里的注释冲掉**

## 公网穿透

`bot-scripts\酒馆穿透.ps1` 用 cloudflared 快速隧道，不用注册、不用 VPS：

```powershell
pwsh -File "E:\YunzaiBot\bot-scripts\酒馆穿透.ps1"          # 起隧道，打印公网地址
pwsh -File "E:\YunzaiBot\bot-scripts\酒馆穿透.ps1" -Check    # 只检查/下载 cloudflared
pwsh -File "E:\YunzaiBot\bot-scripts\酒馆穿透.ps1" -Stop     # 关掉
```

第一次跑会自动下 cloudflared.exe 到 `E:\YunzaiBot\tools\`。

地址是 `https://xxx-yyy-zzz.trycloudflare.com` 这种随机域名，**每次重启都变**，关掉就失效。
隧道开着的时候，任何拿到地址的人都能打开酒馆登录页 —— 所以酒馆的 `basicAuthMode` 一定要开着。

### 实测记录（2026-10-29）

通了：`401`（不带鉴权）→ `200`（带 basic auth，710KB，标题 `SillyTavern`），
跨公网往返 2.4 秒，手机开网页可用。

**踩过的坑：酒馆自己的白名单会挡隧道，报 `403 Forbidden`。**

```
Connection from 127.0.0.1 (forwarded from 2408:8361:...) has been blocked.
```

原因：酒馆 `enableForwardedWhitelist: true` 会去看 `X-Forwarded-For`，
拿到的是手机真正的 IPv6 地址；而 `whitelist` 里通常只有 `0.0.0.0/0`（只覆盖 IPv4）
和 `::1`（只有本机），于是被判成外来 IP。

修法：给 `config.yaml` 的 `whitelist` 补一条 `- ::/0`，然后**重启酒馆**
（这个配置不热加载）。IPv4 那条 `0.0.0.0/0` 本来就已经全放了，加 `::/0` 只是对齐 IPv6。

改完记得把 `basicAuthMode` 继续开着 —— 白名单放全之后，密码就是唯一那道门。

**第二个坑：刚起的域名本机解析不到。**

新域名建好后，本机（或路由器）的 DNS 还缓存着"不存在"，浏览器直接打不开，
但手机上走流量往往一开就通 —— 因为换了一台 DNS。脚本里已经做了处理：
自检失败会 `ipconfig /flushdns` 重试三次。手工排查时先清缓存，或者用
`nslookup 域名 8.8.8.8` 确认域名其实已经解析出来了。

> 借 QQ 做穿透？技术上能做到（QQ 消息当传输层、分片传 HTTP），但实测不可用：
> 消息有频率限制、单文件/单条有大小限制、延迟按秒算，网页根本加载不出来，
> 而且违反平台条款。真要对朋友开放，用 cloudflared / frp + VPS / Tailscale 三选一，
> 都比他绕一大圈的 QQ 中转强。

## 提示词是怎么分层的

这是插件最核心的部分。顺序按"约束力"排：

```
┌─ system ────────────────────────────────┐
│ 1. 核心规则      你不能做什么（防 OOC）    │  ← 权重最高
│ 2. 角色卡        你是谁、怎么说话          │
│ 3. 酒馆状态      我是谁 / 同场有谁          │  ← 有才注入
│ 4. 世界书        这个世界的设定            │  ← 关键词触发
│ 5. 记忆          你还记得的事              │
│ 6. 场景锚        此刻在哪（压过常驻设定）   │  ← 有才注入
│ 7. 交接          刚才是谁在聊（换人时才有） │
│ 8. 场景          现在几点、多久没说话       │
└─────────────────────────────────────────┘
┌─ 对话历史 ──────────────────────────────┐
└─────────────────────────────────────────┘
┌─ system（后置指令）──────────────────────┐
│ 9. "现在你就是XX本人，句子短，不要解释"    │  ← 离输出最近，最难被冲淡
└─────────────────────────────────────────┘
```

**后置指令**是借鉴 SillyTavern 的 `post_history_instructions`。
放在历史之后、离模型输出最近的地方，因为长上下文会把开头的规则冲淡。

想加临时设定就改 `immersion.authorNote`，会并进后置指令。

### 关于"破限"的边界

这个插件做的是**角色沉浸工程**：防 OOC、避免"作为一个AI"打断、允许角色有情绪和亲密表达、
输出清洗掉 AI 腔。

**不做**绕过模型安全策略生成违法违规内容那种事。那不是角色扮演，是别的问题。

## 绘图

需要 [comfy-bridge](../comfy-bridge) 或任何 A1111 兼容接口（`/sdapi/v1/txt2img`）。

```yaml
draw:
  enabled: true
  bridgeUrl: http://127.0.0.1:7860
  loraDir: 'D:\ComfyUI\models\loras'
  knowledgeFile: config/draw-knowledge.md
```

`draw-knowledge.md` 是给模型看的出图知识（tag 结构、性别锚定、常见坑、JSON 输出格式）。
**这份文件可以直接改成你常用的模型习惯**——它每轮都会整份塞进 system prompt。

三种意图：

- `画个猫耳少女` → 新画
- `猫耳，棕发` → 在上一张基础上改（`white hair` → `brown hair`，替换不叠加）
- `还有多久出图` → 报真实进度，**不经过模型**（避免"已经画好了啊"这种编造）

改图有效期默认 30 分钟（`draw.lastPlanTtlMin`），过期就当新画。

## 工具自主调用

默认开启（`tools.enabled: true`）。开启后，角色模型的 system prompt 里会多一段工具说明：

- `[[画:鲸鱼娘趴在窗边晒太阳]]` —— 她聊到兴头上自己决定画一张
- `[[画改:换成夜景]]` —— 把刚画那张改一改
- `[[语音]]` —— 这句话用语音发（需要 `tts.enabled: true`）

插件解析标记 → 剥掉 → 执行，标记不会显示在聊天里。明确说"画个XX"仍走正则意图识别（更快更稳），标记是给"聊着聊着突然想给你看什么东西"这种场景用的。关掉 `tools.enabled` 即回退纯正则。

## 酒馆助手等价层

SillyTavern 的「酒馆助手」（Tavern Helper）能力在 QQ 纯文本通道里的等价实现。全部由**角色卡作者**在卡里声明，不执行任意 JS（QQ 端没有沙箱）：

| 酒馆助手能力 | QQ 等价 | 卡片写法 |
|---|---|---|
| 正则脚本（Regex 扩展） | 对模型输入/输出做查找替换 | front-matter `regex:` 列表 |
| HTML 状态栏渲染 | puppeteer 渲染成图片，`#喵呜 状态栏` 查看 | front-matter `statebar:` HTML |
| 变量系统（get/setvar） | 模型嵌 `[[变量:好感度=+1]]` 记状态（支持相对加减） | 模板里 `{{var:名字}}` 读 |
| 快捷按钮（QuickReply） | 模型嵌 `[[选项:A\|B\|C]]`，用户回数字 | — |
| 宏（`{{user}}` 等） | `{{char}}` `{{user}}` `{{nick}}` `{{date}}` `{{time}}` `{{weekday}}` `{{random:a\|b}}` `{{var:名}}` | — |
| 表情/动作 | 模型嵌 `[[表情:开心]]`，映射成 QQ 小表情 | — |

卡片 front-matter 示例：

```yaml
regex:
  - find: "<think>[\\s\\S]*?</think>"
    replace: ""
    target: output        # output / input / both
statebar: |
  <div style="padding:14px;border-radius:12px;background:#eaf4fb">
    <b>{{char}}</b> 好感度 {{var:好感度}} · 位置 {{var:地点}}
  </div>
```

安全边界：正则规则限长 500、坏正则跳过不炸；宏是纯字符串替换不 eval；变量只存在该用户的存档里。

## 常见问题

**Q：她老是说"作为一个AI"**
A：`immersion.enabled` 确认是 true。还不行就把 `chat.maxReplyChars` 调小到 60，
短回复更难破戏。另外检查用的模型是不是太"助手化"了。

**Q：说话太长、像写作文**
A：`chat.maxReplyChars` 是硬截断，会生效。但根本还是示例对话要写好——
模型靠 `mesExample` 学语气，那部分比规则管用。

**Q：换人之后她不记得之前的事**
A：`cast.handover` 要 true。另外确认 `memory.enabled` 没关。

**Q：压缩之后细节丢了**
A：正常，压缩有损。调大 `compress.triggerTurns`（比如 24）压得晚一点，
或者调大 `compress.maxSummaryChars` 让摘要更详细。

**Q：Redis 没装能用吗**
A：能。全部走本地文件（`data/kv/`），只是没有 TTL 自动过期。
Redis 装好之后启动，数据会自动写到 Redis。

**Q：能和别的对话插件同时开吗**
A：会抢消息。同时开的时候优先级高的先 `accept` 并 `return`，优先级低的收不到。
建议只启用一个。

**Q：换人之后她开场白说了，但刚才的对话还在？**
A：对，这是故意的。记忆是共享的——她开场是"重新露个面"，不是"失忆"。
她 system 里有交接说明，知道刚才是别人在聊。想真的重开一段就 `#喵呜 新建档`。

**Q：`出场` 要打 id 吗，记不住 `yinghua` 这种**
A：id 和中文名都认。`#喵呜 出场 栗子` 和 `#喵呜 出场 lizi` 是一回事，
`同场` / `人设` / `改人设` 也一样。

**Q：存档名能用中文吗**
A：能。冒号、斜杠、空格这类字符会被换成下划线（`#喵呜 存档` 里能看到实际名字）。
「工作」和「生活」是两份独立记忆，Redis key 和落盘文件名都不会撞。

**Q：写人设写的卡在哪**
A：`config/characters/<id>.md`（id 由模型给，中文名会转义）。写完发
`#喵呜 重载` 就能 `#喵呜 出场 <id>` 用上。改坏了 `ahui.md.bak-<时间戳>` 就是旧版。

**Q：`同场` 和 `出场` 有什么区别**
A：`出场` 是换主角，记忆共用人格换。`同场` 是"她旁边还站着一个人"——
只把对方的姓名和 80 字摘要塞进 system，主角还是当前这张卡。

**Q：网页控制台打不开**
A：先确认日志里有 `[喵呜] WebUI 已启动`。打不开通常是端口被占（会打 warn 并跳过启动）。
换个端口就改 `webui.port`，然后重启机器人（端口是启动时绑定的）。
密码忘了：把 `webui.password` 改成空，重启会生成新的并打日志。

**Q：从酒馆接着聊之后，她说话变味了**
A：`接着` 会把酒馆里那 12 轮原文塞进上下文，模型很容易被对方（也就是你在酒馆里）
的说话方式带跑。两个办法：`#喵呜 压缩` 把它压成摘要，或者少接一点
（调小 `chat.maxTurns`，接的轮数跟着变）。

**Q：帮助为什么变成图片了**
A：命令多了以后一条文字消息塞不下，QQ 里还会被折叠。图片是云崽自带的 puppeteer 渲染的，
失败会自动回落到文字版（比如在没有浏览器环境的测试脚本里）。

**Q：酒馆的预设能直接用在 QQ 里吗**
A：能搬规则，不能搬全部。`#喵呜 酒馆 预设 xxx 应用` 只取 jailbreak 段落塞进后置指令；
main / 世界书插入位置 / 正则替换这些酒馆前端的功能没有对应物。
